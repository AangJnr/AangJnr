## Cloopp (Recycle Box)

A Flutter-based mobile app for Android and iOS utilizing the Stacked architecture. It enables users to effortlessly find nearby recycling centers and monitor their recycling efforts, promoting environmental consciousness and sustainability.

🔗 [cloopp.com](https://cloopp.com/)

**Tech stack:** Dart · Flutter · Camera2 API · Google Maps · REST APIs
