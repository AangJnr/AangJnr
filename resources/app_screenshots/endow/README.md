## Endow Payments – Create. Share. Receive.

**Endow** is a payment platform designed to simplify contributions for meaningful causes. Generate payment links to collect money transparently for a shared cause where a group needs to contribute fast and without friction.

🔗 [ndow.link](https://ndow.link)

**Tech stack:** Vue.js · Node.js · Flutter · Firebase · Google Cloud Platform · Cloud Messaging
