## DependrScoots – Scooter Rental App

DependrScoots delivers seamless scooter sharing with real-time tracking, transparent pricing, and a powerful dashboard for fleet operators. The SaaS ecosystem consists of a Backend, an admin dashboard, and mobile apps for Android and iOS.

🔗 [dependerscoots-admin.vercel.app](https://dependerscoots-admin.vercel.app/)

**Tech stack:** Flutter · FastAPI · Vue.js · Supabase · Google Cloud Platform
