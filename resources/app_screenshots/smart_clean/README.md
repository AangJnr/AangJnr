## Robot Control Queuing System (Smart Clean)

As a Full Stack Engineer, I designed and implemented a complete live streaming pipeline on a Raspberry Pi using Dockerized services. The system ingests RTSP feeds from IP cameras, transcodes them, and serves the streams through a custom web frontend with fallback support. Built the frontend in TypeScript (Vite), integrated real-time queuing robot session controls, and managed secure external access with automatic TLS provisioning using Ngrok.

🔗 [smartclean-1333e.web.app](https://smartclean-1333e.web.app)

**Tech stack:** TypeScript · Vite · Node.js · Raspberry Pi · Firebase · Stream Processing
