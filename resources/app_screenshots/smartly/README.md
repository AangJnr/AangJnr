## Smart Advertisement Platform

A smart advertisement platform that allows users to configure ads on an Admin panel webapp to be displayed on Android TVs, Android tablets, and iOS iPad devices.

**Main Features:**
1. Advertisement tailored to specific user groups
2. Ad formats to change the behavior and positioning of ads on devices
3. User device ad tracking
4. Real-time ad updates
5. Analytics and Ad Impressions

**Tech stack:** Android Tablet · iPad App Development · Web Design · Analytics
