## Wholesome Craft – Meal Plan App

Crafted with Kotlin for Android, Wholesome Craft is a user-friendly meal planning application. It helps users to create and manage their meal plans effortlessly, offering recipe suggestions, grocery lists, and nutritional insights.

🔗 Available on [Android](https://play.google.com/store/apps/details?id=co.effectstudios.wholesomecraft&hl=en) · [wholesomecraftghana.com](https://wholesomecraftghana.com/)

**Tech stack:** Kotlin · Android XML · Espresso · JUnit · REST APIs
