## Wine2U – Wine Delivery Platform

Wine2U is a delivery platform that connects wine enthusiasts with local sellers, providing a seamless and personalized experience for discovering and ordering wines. The app simplifies browsing wine collections, placing orders, and tracking deliveries.

**Key Features:**
- Intuitive interface for browsing and discovering wines based on user preferences
- Seamless Payments: Secure and flexible payment options
- User Personalization: Tailored recommendations based on user tastes and order history

**Tech stack:** Flutter · Firebase · Node.js · API
